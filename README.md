# Assignment 3 - University Course Management System

## File Structure
- **models.js**: Defines the Student class with immutable ID property using Object.defineProperty().
- **database.js**: Simulates asynchronous data fetching using setTimeout and callbacks.
- **analytics.js**: Contains analytical functions like calculateClassAverage, findTopStudent, and filterStudents.
- **main.js**: Orchestrates the program execution and tests immutability and analytics.

## Challenges
- Ensuring strict immutability of the student ID.
- Handling asynchronous flow with callbacks and array methods.
